          Laatste wijzigingen

            Hoe maak ik een GitHub-sleutel?
            1. Ga naar github.com/settings/personal-access-tokens/new (of: profielfoto, Settings, Developer settings, Personal access tokens, Fine-grained tokens).
            2. Geef de sleutel een naam, bijvoorbeeld Werkplaats, en kies hoe lang hij geldig blijft, bijvoorbeeld 90 dagen.
            3. Kies bij Repository access voor Only select repositories en selecteer alleen mijn-website.
            4. Zet bij de permissies Contents op Read and write, en Pages ook op Read and write. Met Pages kan de werkplaats GitHub zelf vragen je site op te bouwen en precies zien wanneer je update live staat.
            5. Klik op Generate token en kopieer de sleutel meteen. GitHub laat hem maar één keer zien.
